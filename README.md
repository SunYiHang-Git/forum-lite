# Vue 3 + TypeScript + Vite

# 本项目只作为模板使用，项目内包含了不可缺少基本的功能，不可以编辑本项目进行开发，应该拷贝一份再开发,后续有增加模板功能，将继续完善

# 作为子应用使用步骤

1. 使用Admin 用户打开RPAWeb，在系统管理菜单下有个 微前端管理菜单，打开进行项目及菜单配置

2. 填写自己的路由页面配置文件 /src/router.js

3. 打包 运行 npm run build

4. 将打包生成 dist/app-dist-xxx 整体复制到 RPAWeb服务器目录下的web文件夹下即可

# 注意：app-dist-xxx 必须项目配置里面的 项目文件夹保存一致
